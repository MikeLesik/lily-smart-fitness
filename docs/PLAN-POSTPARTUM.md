## Что уже сделано (каркас, ветка `cabinet`)

- «Доступ навсегда» убран из общих текстов сайта и из пункта 4.3 оферты: срок теперь свойство программы.
- Водяной знак: поверх платного видео в кабинете виден email зрительницы, он переезжает по кадру раз в 15–25 секунд. Свой полноэкранный режим, чтобы знак не пропадал.
- Тестовые программы («Сильные ягодицы», «Утренняя зарядка») и набор сняты с сайта (`published: false`).
- Одно устройство на аккаунт: платное видео играет только там, где его открыли последним. На прежнем устройстве через 30 секунд плеер сменяется сообщением и кнопкой «Смотреть здесь». Миграция `0004_playback_holders`.

## Интеграция Kinescope (по документации на 25.11.2026, вживую не проверено)

- Регистрация: https://app.kinescope.io/user/create. Бесплатный тариф без DRM и без пробного периода. DRM входит в тариф Super: от €10 в месяц, трафик €0,03 за ГБ, хранение €0,03 за ГБ, перекодирование €0,01 за минуту.
- DRM включается на весь проект (настройки проекта, Enable Encryption), обработка до суток, выключить может только поддержка. Поэтому платные видео держать в отдельном проекте.
- Не играет с DRM: Firefox ESR на компьютере, Firefox и UC на Android, режим инкогнито Chrome на Android.
- Кто может смотреть, решает наш сервер через Authorization backend:
  - настройка: `PUT https://api.kinescope.io/v1/drm/auth/{PROJECT_ID}` с телом `url`, `username`, `password` (Basic auth), `strict: true`;
  - наша страница добавляет к адресу плеера `?drmauthtoken=<JWT>`; токен выпускаем сами (короткий срок, id зрительницы и видео);
  - при каждом запросе лицензии Kinescope шлёт на наш адрес POST с JSON `{id, type, token, ip, user_agent}`; ответ 200 разрешает, 403 запрещает, тело не читается, таймаут 5 секунд.
- Это защищает только выдачу лицензии. Дополнительно ограничить встраивание доменом lily.coach (настройка проекта «On specified domains»).
- Плеер: `https://kinescope.io/embed/<VIDEO_ID>?drmauthtoken=…&watermark=<email>`; у iframe в `allow` обязательно `encrypted-media`. Параметр `watermark` работает, только если водяные знаки включены в кабинете Kinescope. На каком тарифе они доступны, в документации не указано.
- API: `https://api.kinescope.io`, заголовок `Authorization: Bearer <token>` (токен создаётся в Settings → API). Статус и длительность видео: `GET /v1/videos/:video_id`. Список: `GET /v1/videos?project_id=…`. Загрузка: `POST https://uploader.kinescope.io/v2/video` с заголовками `X-Parent-ID`, `X-Video-Title`.
- Не найдено в документации: ограничение одновременных просмотров на зрителя (делаем сами), работа CDN в России (проверить вживую), нужен ли свой сертификат Apple для FairPlay (судя по документации, нет).
