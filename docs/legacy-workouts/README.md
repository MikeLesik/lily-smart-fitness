# Июньский раздел «Видеотренировки» (заменён кабинетом)

Модель с внешними ссылками оплаты (Prodamus / Lemon Squeezy), окном выбора платёжки и доступом через закрытый Telegram-канал снята на этапе 4: покупка теперь через Stripe Checkout, доступ в `/account/`.

Здесь для этапа 5 (`/programs/<slug>/`) сохранены вёрстка лендинга курса (`TEMPLATE_course.ru.html`, `TEMPLATE_course.en.html`) и полный старый `workouts.css` со стилями лендинга. В `src/` эти файлы больше не публикуются. Пути к CSS и JS в шаблонах старые.
